## Folders, and per-folder agent visibility

Memories now live in folders, and each agent is either allowed everywhere or
restricted to your non-sensitive ones. Mark a folder sensitive and a restricted
agent cannot read what is in it.

**Upgrading an existing vault:** your memories are filed into folders the first
time you open 2.0. Nothing is deleted, and no agent gains access it did not
already have.

## Also new

- **The app shows its version**, bottom-left, and can check for updates. This is
  the release that makes future updates visible at all — 1.0.1 had no way to
  tell you a new one existed. Automatic checking is opt-in during setup.
- **Superseded memories.** When a fact changes, the new memory records that it
  replaces the old one instead of overwriting it, and the old entry stays
  readable with its chain intact.
- **Better imports.** On-device extraction works properly on Apple Intelligence
  machines, long documents are chunked rather than truncated, and an import that
  finds nothing now says why instead of reporting a silent success.
- **Blocked reads are recorded.** When a restricted agent is refused, the audit
  log says so and the caller is told results were withheld. Previously the
  refusal worked but left no trace, so a fully blocked search looked exactly
  like one that found nothing.
- **Older macOS** degrades gracefully instead of failing to build features it
  cannot run.

## If you built anything against the MCP tools

`memory_search` now returns a compact index — id, title, tags — rather than full
bodies, and `memory_get` fetches the bodies you actually want. Agents using
Localmem through the normal tool descriptions need no changes; direct
integrations that assumed search returned complete memories do.

## Installing

Drag Localmem to your Applications folder, replacing the old copy, and reopen
it. Your memories live outside the app bundle and are untouched, and every AI
client stays connected — the path they were registered with does not change.
